# Security Policy

## Supported Versions

| Version | Supported          |
| ------- | ------------------ |
| 2.0.x   | :white_check_mark: |
| < 2.0   | :x:                |

## Reporting a Vulnerability

If you discover a security vulnerability in **Kitchen**, please do **not** open a public issue.

Instead, please send an email with details, reproduction steps, and potential impact to:
**prokin.o@gmail.com**

You should receive a response within 48 hours. Please give us reasonable time to investigate and release a fix before publicly disclosing the issue.
